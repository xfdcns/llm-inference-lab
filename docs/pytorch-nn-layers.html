torch.nn 层完整速查表

按功能分类 · 含关键参数与张量形状 · 标注高频层。命名空间 torch.nn 下约 100 个 Module 子类，此处覆盖常用与易混的全部。
— 个结果
容器 线性 卷积 池化 填充 归一化 激活 Dropout 嵌入 循环 Transformer 形状变换 损失 距离 选型
没有匹配的层，换个关键词试试。

1 容器与组合 containers

它们本身是 Module，作用是"装别的层"。区别只在前向逻辑谁来写、是否需要命名。

nn.Sequential
Sequential(*args)
顺序串联，自动生成 forward。
x → layer1 → layer2 → ... → y
nn.ModuleList
ModuleList(modules=None)
只负责注册子模块，前向必须自己写循环。适合层数动态或带分支的结构。
nn.ModuleDict
ModuleDict(modules=None)
按字符串键注册，用 key 取层。代替"用 dict 存模块"的错误做法。
nn.ParameterList
ParameterList(values=None)
装 nn.Parameter 而非 Module，用于可学习的系数向量等。
nn.ParameterDict
ParameterDict(values=None)
按名字管理的参数集合。

2 线性与全连接 linear

最基础的仿射变换，参数量 = in × out (+ out)。

nn.Linear
Linear(in_features, out_features, bias=True)
y = xWᵀ + b。只作用于最后一维，前面的维度都是 batch。
(*, in_features) → (*, out_features)
nn.Bilinear
Bilinear(in1_features, in2_features, out_features)
y = x₁ᵀ A x₂ + b，双线性交互，常见于 VQA、推荐。
(N, in1), (N, in2) → (N, out)
nn.LazyLinear
LazyLinear(out_features)
首次前向时自动推断 in_features，省去手算维度。参数在第一次 forward 后才出现。
nn.Identity
Identity(*args, **kwargs)
原样返回输入。做消融实验、占位、替换某一层时用。

3 卷积 convolution

核心参数永远这四个：kernel_size / stride / padding / dilation，外加 groups 决定分组方式。

nn.Conv1d
Conv1d(in_ch, out_ch, k, stride=1, padding=0, dilation=1, groups=1)
一维卷积，用于序列、音频、文本。
(N, C, L) → (N, C_out, L_out)
nn.Conv2d
Conv2d(in_ch, out_ch, k, stride=1, padding=0, dilation=1, groups=1)
二维卷积，视觉主力。groups=in_ch=out_ch 即 depthwise；1<groups<in_ch 为分组卷积。
(N, C, H, W) → (N, C_out, H_out, W_out)
nn.Conv3d
Conv3d(in_ch, out_ch, k, ...)
三维卷积，视频、医学体数据。
(N, C, D, H, W) → (N, C_out, D', H', W')
nn.ConvTranspose2d
ConvTranspose2d(in_ch, out_ch, k, stride, padding, output_padding)
转置卷积，用于上采样/解码器。stride 与 kernel 不整除时会出现棋盘格伪影。
(N, C, H, W) → (N, C_out, ≈H·stride, ≈W·stride)
nn.ConvTranspose1d / 3d
同 ConvTranspose2d 的 1D / 3D 版本
语音合成、视频生成里的上采样。
nn.LazyConv2d
LazyConv2d(out_ch, k, ...)
自动推断 in_channels。
nn.Unfold
Unfold(kernel_size, dilation=1, padding=0, stride=1)
im2col：把滑窗展平成列，用矩阵乘实现卷积。
(N, C, H, W) → (N, C·kh·kw, L)
nn.Fold
Fold(output_size, kernel_size, ...)
Unfold 的逆操作，把列还原成图。

4 池化 pooling

全部无参数。用 Adaptive 版本可以彻底摆脱"输入尺寸必须整除"的束缚。

nn.MaxPool2d
MaxPool2d(kernel_size, stride=None, padding=0, dilation=1, return_indices=False)
窗口取最大值。stride 默认等于 kernel_size。
(N, C, H, W) → (N, C, H/k, W/k)
nn.MaxPool1d / 3d
同 2D 版本
序列与体数据的最大值池化。
nn.MaxUnpool2d
MaxUnpool2d(kernel_size, stride, padding)
反池化，必须传入 MaxPool 记录下来的 indices（segnet 类结构用）。
nn.AvgPool2d
AvgPool2d(kernel_size, stride=None, padding=0, count_include_pad=True)
窗口取平均。
nn.AdaptiveAvgPool2d
AdaptiveAvgPool2d(output_size)
直接指定输出尺寸，GAP 就写 output_size=(1,1)。让网络接受任意输入分辨率。
(N, C, H, W) → (N, C, 1, 1)
nn.AdaptiveMaxPool2d
AdaptiveMaxPool2d(output_size)
同上，取最大值版本。
nn.LPPool2d
LPPool2d(norm_type, kernel_size)
Lp 范数池化，norm_type=1 近似平均、→∞ 近似最大。
nn.FractionalMaxPool2d
FractionalMaxPool2d(kernel_size, output_ratio)
分数阶最大池化，带随机性，可作数据增强。

5 填充 padding

1D / 2D / 3D 都有对应版本；日常更常用函数式 F.pad(x, (l, r, t, b), mode=...)。

nn.ConstantPad2d / nn.ZeroPad2d
ConstantPad2d(padding, value) / ZeroPad2d(padding)
常数填充，ZeroPad 就是 value=0 的特例。
nn.ReflectionPad2d
ReflectionPad2d(padding)
镜像反射填充，边缘更自然，超分/风格迁移常用。
nn.ReplicationPad2d
ReplicationPad2d(padding)
复制边缘像素填充，不会引入虚假的对称结构。
nn.CircularPad2d
CircularPad2d(padding)
循环填充，适合周期性信号（如全景图、音频）。

6 归一化 normalization

区别只在"沿哪些维度统计均值方差"。选错是训练不收敛的头号原因之一。

nn.BatchNorm2d
BatchNorm2d(num_features, eps=1e-5, momentum=0.1, affine=True, track_running_stats=True)
沿 (N, H, W) 统计，每个通道一组统计量。依赖 batch size，小 batch 会崩。
train / eval 行为不同：eval 用 running_mean。
nn.BatchNorm1d / 3d
同 2D 版本
1D 用于 (N, C) 或 (N, C, L)。
nn.LayerNorm
LayerNorm(normalized_shape, eps=1e-5, elementwise_affine=True)
对每个样本的最后一维（或几维）归一化，与 batch 无关。Transformer 标配。
(..., normalized_shape) → 同形状
nn.GroupNorm
GroupNorm(num_groups, num_channels)
通道分组后组内归一化，小 batch 友好，是 BN 的常用替代。
nn.InstanceNorm2d
InstanceNorm2d(num_features, affine=False)
每个样本每个通道独立归一化，风格迁移标配。
nn.RMSNorm
RMSNorm(normalized_shape, eps=None, elementwise_affine=True)
只除以均方根、不减均值。LLaMA 系列使用，比 LayerNorm 省一点计算。
nn.SyncBatchNorm
SyncBatchNorm(num_features, ...)
多卡跨 GPU 同步统计量，单卡 batch 太小、又必须用 BN 时的解法。
nn.LocalResponseNorm
LocalResponseNorm(size, alpha, beta, k)
AlexNet 时代的通道侧抑制，现在基本被 BN 取代。

7 激活函数 activations

现代默认选择：视觉用 GELU / SiLU，LLM 用 SwiGLU（GLU 变体）；不要再堆 Sigmoid。

nn.ReLU
ReLU(inplace=False)
max(0, x)。inplace=True 省显存，但与残差/需保留输入的场景冲突。
nn.ReLU6
ReLU6(inplace=False)
上界截断到 6，移动端量化模型常用。
nn.LeakyReLU
LeakyReLU(negative_slope=0.01, inplace=False)
负半轴留一个斜率，缓解 ReLU 死区。
nn.PReLU
PReLU(num_parameters=1, init=0.25)
斜率可学习（有参数）。
nn.RReLU
RReLU(lower=1/8, upper=1/3, inplace=False)
负半轴斜率在训练时随机采样，起正则作用。
nn.ELU
ELU(alpha=1.0, inplace=False)
负半轴指数饱和，输出均值更接近 0。
nn.SELU
SELU(inplace=False)
配合自归一化网络（权重用 Lecun 初始化）时能保持激活分布稳定。
nn.CELU
CELU(alpha=1.0)
ELU 的连续可导变体。
nn.GELU
GELU(approximate='none')
高斯误差线性单元，BERT/GPT/ViT 标配。approximate='tanh' 更快。
nn.SiLU
SiLU(inplace=False)
即 Swish：x·σ(x)。LLaMA、ConvNeXt 使用。
nn.Mish
Mish(inplace=False)
x·tanh(softplus(x))，平滑且非单调，YOLOv4 之后常见。
nn.Hardswish
Hardswish(inplace=False)
SiLU 的分段线性近似，移动端友好。
nn.Hardsigmoid
Hardsigmoid(inplace=False)
Sigmoid 的线性近似。
nn.Hardtanh
Hardtanh(min_val=-1, max_val=1)
区间截断。
nn.Sigmoid
Sigmoid()
压到 (0,1)，只建议用在门控和二分类输出层。
nn.Tanh
Tanh()
压到 (-1,1)，RNN 内部使用。
nn.Softplus
Softplus(beta=1, threshold=20)
平滑版 ReLU，输出恒正；方差参数化的网络里用。
nn.Softsign
Softsign()
x/(1+|x|)，比 tanh 饱和更慢。
nn.Softmax
Softmax(dim=None)
归一化成概率。dim 必须显式给，否则 2D 以上会警告。
nn.LogSoftmax
LogSoftmax(dim=None)
log 概率，与 NLLLoss 搭配比 CrossEntropy 更省一点数值稳定开销。
nn.Softmin
Softmin(dim=None)
对负值做 softmax，相当于"取最小"的软版本。
nn.GLU
GLU(dim=-1)
门控线性单元：把通道对半分，一半做门。SwiGLU = GLU + SiLU。
nn.Threshold
Threshold(threshold, value)
低于阈值就替换为定值，很少直接用。

8 Dropout 与正则 regularization

只在 model.train() 下生效，eval() 时自动关闭——这也是"忘记切 eval 导致验证结果抖动"的根源。

nn.Dropout
Dropout(p=0.5, inplace=False)
逐元素随机置零，训练时按 1/(1-p) 缩放保持期望不变。
nn.Dropout1d
Dropout1d(p=0.5)
整通道丢弃（(N,C,L) 上按通道），用于 1D 特征。
nn.Dropout2d
Dropout2d(p=0.5)
整通道丢弃，比逐元素更能保留空间相关性。
nn.Dropout3d
Dropout3d(p=0.5)
3D 版整通道丢弃。
nn.AlphaDropout
AlphaDropout(p=0.5)
保持均值方差不变，配合 SELU 使用。
nn.FeatureAlphaDropout
FeatureAlphaDropout(p=0.5)
整通道版 AlphaDropout。

9 嵌入 embedding

本质是一张可训练的查找表，参数量 = num_embeddings × embedding_dim，词表大时非常占显存。

nn.Embedding
Embedding(num_embeddings, embedding_dim, padding_idx=None, max_norm=None, sparse=False)
整数索引查表。padding_idx 的向量固定为 0 且不更新梯度。
(N, L) 整型 → (N, L, D)
nn.EmbeddingBag
EmbeddingBag(num_embeddings, embedding_dim, mode='mean')
查表后直接聚合（sum/mean/max），不展开成 L×D，省内存。变长序列友好。
索引 + offsets → (N, D)

10 循环网络 recurrent

默认 batch_first=False，输入是 (seq_len, batch, feature)。几乎所有"形状对不上"的报错都源于此。

nn.LSTM
LSTM(input_size, hidden_size, num_layers=1, batch_first=False, bidirectional=False)
长短期记忆，输出 (output, (h_n, c_n))。
(L, N, in) → (L, N, H·dirs)
nn.GRU
GRU(input_size, hidden_size, ...)
门控循环单元，比 LSTM 少一个门，参数更少、常常效果相当。
nn.RNN
RNN(input_size, hidden_size, nonlinearity='tanh')
最朴素的循环层，长序列梯度消失严重。
nn.LSTMCell / nn.GRUCell / nn.RNNCell
Cell(input_size, hidden_size)
只算一个时间步，需要自己写循环。适合自定义控制流。

11 Transformer 与注意力 transformer

想自己搭结构用 MultiheadAttention；想开箱即用直接上 Transformer 系列；追求速度用函数式 SDPA。

nn.MultiheadAttention
MultiheadAttention(embed_dim, num_heads, dropout=0.0, batch_first=False)
多头注意力。q=k=v 是自注意力；q 来自解码器、k/v 来自编码器就是交叉注意力。
(L, N, E) → (L, N, E) + 权重
nn.TransformerEncoderLayer
TransformerEncoderLayer(d_model, nhead, dim_feedforward=2048, dropout=0.1, activation='relu', norm_first=False)
单层编码器：自注意力 + FFN + 两个残差归一化。norm_first=True 是 Pre-LN，训练更稳。
nn.TransformerDecoderLayer
TransformerDecoderLayer(d_model, nhead, ...)
单层解码器：带掩码自注意力 + 交叉注意力 + FFN。
nn.TransformerEncoder
TransformerEncoder(encoder_layer, num_layers, norm=None)
把同一层复制 num_layers 份堆叠，可选最后加一个 LayerNorm。
nn.TransformerDecoder
TransformerDecoder(decoder_layer, num_layers, norm=None)
解码器堆叠。
nn.Transformer
Transformer(d_model=512, nhead=8, num_encoder_layers=6, num_decoder_layers=6, dim_feedforward=2048)
完整编码器-解码器架构，含位置编码与输出投影。

12 形状变换与上采样 shape & upsample

这些层没有参数，只改布局。写模型时用它们代替裸的 view/reshape，形状会写进 state_dict 之外的显式声明里，更好读。

nn.Flatten
Flatten(start_dim=1, end_dim=-1)
展平连续维度，保留 batch 维。
(N, C, H, W) → (N, C·H·W)
nn.Unflatten
Unflatten(dim, unflattened_size)
Flatten 的逆操作。
nn.Upsample
Upsample(size=None, scale_factor=None, mode='nearest')
插值上采样。mode 可选 nearest / bilinear / bicubic。
nn.PixelShuffle
PixelShuffle(upscale_factor)
亚像素卷积：把通道重排成空间分辨率，无插值伪影，超分常用。
(N, C·r², H, W) → (N, C, H·r, W·r)
nn.PixelUnshuffle
PixelUnshuffle(downscale_factor)
PixelShuffle 的逆操作。
nn.ChannelShuffle
ChannelShuffle(groups)
通道分组打乱，ShuffleNet 的核心操作。

13 损失函数 losses

它们也是 Module，所以能挂进 Sequential、也能注册进模型。默认 reduction='mean'。

nn.CrossEntropyLoss
CrossEntropyLoss(weight=None, ignore_index=-100, label_smoothing=0.0)
内部已含 LogSoftmax。输入是 logits，不要自己再套 Softmax。
(N, C) logits + (N,) 类别 → 标量
nn.BCEWithLogitsLoss
BCEWithLogitsLoss(pos_weight=None)
Sigmoid + BCE 的数值稳定版，多标签/二分类首选。pos_weight 处理正负样本不均衡。
nn.BCELoss
BCELoss(weight=None)
输入必须已经过 Sigmoid，容易数值溢出，一般用上面那个。
nn.NLLLoss
NLLLoss()
配合 LogSoftmax 使用，等价于 CrossEntropyLoss。
nn.MSELoss
MSELoss(reduction='mean')
均方误差，回归任务。对离群点敏感。
nn.L1Loss
L1Loss()
绝对值误差，对离群点更鲁棒，但在 0 点不可导。
nn.SmoothL1Loss
SmoothL1Loss(beta=1.0)
Huber 损失，小误差用 L2、大误差用 L1。检测框回归标配。
nn.KLDivLoss
KLDivLoss(log_target=False)
KL 散度，蒸馏时用。注意输入要先取 log。
nn.TripletMarginLoss
TripletMarginLoss(margin=1.0, p=2)
三元组损失，度量学习/检索。需要 anchor/positive/negative 三个输入。
nn.CosineEmbeddingLoss
CosineEmbeddingLoss(margin=0.0)
按标签把相似对拉近、不相似对推远。
nn.MarginRankingLoss
MarginRankingLoss(margin=0.0)
排序损失，要求正样本得分高于负样本至少 margin。
nn.HingeEmbeddingLoss
HingeEmbeddingLoss(margin=1.0)
合页损失，常用于判断两个输入是否相似。
nn.MultiLabelSoftMarginLoss
MultiLabelSoftMarginLoss()
多标签分类的合页式损失。
nn.CTCLoss
CTCLoss(blank=0, zero_infinity=False)
无对齐序列损失，语音识别标配。
nn.PoissonNLLLoss
PoissonNLLLoss(log_input=True)
泊松负对数似然，计数类回归。
nn.GaussianNLLLoss
GaussianNLLLoss()
异方差回归：模型同时预测均值和方差。

14 距离与相似度 distance

nn.CosineSimilarity
CosineSimilarity(dim=1, eps=1e-8)
逐样本余弦相似度，检索/对比学习里算相似矩阵。
(N, D), (N, D) → (N,)
nn.PairwiseDistance
PairwiseDistance(p=2.0, eps=1e-6)
逐样本 p 范数距离。

附 选型速查 cheatsheet

上面是"有什么"，这里回答"用哪个"。

场景选择理由
归一化 CNN + 大 batch → BatchNorm2d；小 batch → GroupNorm；Transformer / NLP → LayerNorm；LLM → RMSNorm 区别在于沿哪几个维度统计，以及是否依赖 batch size
激活 视觉 → GELU 或 SiLU；LLM FFN → SwiGLU；移动端 → ReLU6 / Hardswish ReLU 已不是默认最优解，但仍是基线
上采样 语义分割 → ConvTranspose2d + BN；超分 → PixelShuffle；简单放大 → Upsample(bilinear) 转置卷积有棋盘格缺陷，像素重排无插值伪影
全局池化 AdaptiveAvgPool2d((1,1)) 摆脱输入尺寸约束，同时替代巨大的全连接层
注意力 自建结构 → MultiheadAttention；追求速度 → F.scaled_dot_product_attention SDPA 会走 FlashAttention / 内存高效内核
分类损失 单标签 → CrossEntropyLoss；多标签 → BCEWithLogitsLoss 前者内部含 softmax，后者内部含 sigmoid，都吃 logits
容器 纯串行 → Sequential；有分支/残差 → ModuleList + 手写 forward Sequential 无法表达 if 与跳连
